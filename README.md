# Node.js CRUD Notes API

This is a simple **CRUD (Create, Read, Update, Delete)** API built with **pure Node.js** and the **`http`** and **`fs`** core modules. It allows you to store and manage notes in a `notes.json` file without any third-party frameworks like Express.

## 📌 Features

- ✅ Create new notes (`POST /notes`)
- ✅ Get all notes (`GET /notes`)
- ✅ Get a note by ID (`GET /notes/:id`)
- 🧪 Data is stored in a local `notes.json` file
- 🛠 Built using only native Node.js modules
